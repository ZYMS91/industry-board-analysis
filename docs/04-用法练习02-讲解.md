## 0. 先建一个心智模型（这节看懂，后面大半不用背）

Python 里不管是读代码还是写代码，只有两个动作：**存一个值**、**取一个值**。

### 存：`名字 = 值`

```python
n = 90
```

`=` **不是「等于」**，是「把右边的值贴上左边的名字」。所以：

```python
a = b = 1     # 数字 1 贴了两个名字：a 和 b
a = 2         # 现在名字 a 改贴到 2 上，b 还是 1
```

但右边如果是**可变的东西**（列表、字典），两个名字会指向**同一个东西**：

```python
a = b = []
a.append(1)   # b 也变成 [1]，因为 a 和 b 是同一个列表的两个名字
```

### 取：只有三种方式

| 方式 | 长相 | 适用于 |
|---|---|---|
| ① 用名字 | `nums` | 什么都行 |
| ② 按下标（位置） | `lst[0]`、`text[:3]` | 有顺序的东西：字符串、列表、DataFrame 的列 |
| ③ 按键（名字） | `d["行数"]` | 有名字的东西：字典 |

**判断口诀**：这个数据**有位置**就用 `[数字]`，**有名字**就用 `["文字"]`，**两个都没有就不能用 `[]`**。

两个都没有的就是**集合（set）**——集合只回答「有没有」，不回答「第几个」。这是后面所有疑惑的源头。

## 1. 五种数据长什么样（这是你最大的缺口，先补这个）

| 类型               | 长相                     | 怎么取一个                                                                                                | 项目里在哪            |
| ---------------- | ---------------------- | ---------------------------------------------------------------------------------------------------- | ---------------- |
| **str 字符串**      | `"上涨 72 个"`            | `s[0]` 取第一个字；`s[1:3]` 取一段                                                                            | 摘要文案、子进程输出       |
| **list 列表**      | `["72", "423", "1"]`   | `lst[0]`、`lst[-1]` 最后一个                                                                              | `re.findall` 的返回 |
| **dict 字典**      | `{"行数": 90, "上涨": 11}` | `d["行数"]`；`d.get("行数")` 没有时返回 None 而不是报错                                                             | `nums`           |
| **set 集合**       | `{"72", "423"}`        | **不能用 `[]`**。`s[0]` 直接报 `TypeError: 'set' object is not subscriptable`。只能 `"72" in s` 或 `for x in s` | `allowed`        |
| **DataFrame 表格** | 一张有列名的二维表              | `df["涨跌幅"]` 取一整列；`df.loc[0, "涨跌幅"]` 取一个格子                                                            | 全部行情数据           |

### 列表 vs 集合：为什么校验要用集合

| | list 列表 | set 集合 |
|---|---|---|
| 有没有顺序 | 有（能说第 0 个是谁） | **没有** |
| 能不能重复 | 能 | **自动去重** |
| 查「有没有」快不快 | 慢（一个个比） | 快（一步定位） |
| 能不能切片 | 能 `lst[:3]` | **不能** |

**这就是「两个数字对调位置拦不住」的最硬解释**：`allowed` 是集合，它只记得「有哪些数字」，**没有顺序、没有标签**，所以它根本无从知道「72 应该跟在『上涨』后面」。它只能回答「72 在不在我这儿」。

## 2. 逐句讲解

读法总纲（背下来）：**点号 = 对左边这东西做下一步；括号 = 干活（里面是原料）；等号 = 给结果起个名字。**

```python
head = "\n".join( out.stdout.splitlines()[:3] )
 │      │                │            │
 │      │                │            └─ ③ 切片：取前 3 个
 │      │                └────────────── ② 按行切成列表
 │      └─────────────────────────────── ① 用换行把它们粘回去
 └────────────────────────────────────── 结果存进名字 head
```

### 第 1 句 `found = re.findall(r"-?\d+\.?\d*", text)`

**人话**：从 `text` 这段文字里，把**所有长得像数字的片段**找出来，放进 `found`（一个列表）。

**语法点**：

1. **`re.findall(规则, 文字)`** —— `re` 是 Python 自带的正则库。`findall` 顾名思义：find all，找出全部，返回**列表**。
2. **`r"..."` 的 `r`** —— raw string。因为反斜杠 `\` 在普通字符串里是「转义符」（`\n` 是换行），正则里到处要写反斜杠，加个 `r` 就告诉 Python：**别转义，原样给我**。
3. **正则符号表**（这就是全部难点，记住这 5 个够用）：

| 写法 | 意思 |
|---|---|
| `\d` | 一个数字（0-9）。**d = digit**，不是「指数」 |
| `+` | 前面那个东西 **1 个或多个** |
| `*` | 前面那个东西 **0 个或多个** |
| `?` | 前面那个东西 **可有可无**（0 个或 1 个） |
| `\.` | 一个真正的「点」。（点本身在正则里是「任意字符」，所以要转义） |

**合起来读**：`-?` 可选的负号 → `\d+` 至少一个数字 → `\.?` 可选的小数点 → `\d*` 零个或多个数字。也就是「带符号的整数或小数」。

**为什么必须这么写**：摘要里会有 `上涨 72 个，跌 -0.43`，要自动把 `72`、`-0.43` 抠出来比对，不可能靠人眼。

**自己试**（粘到 Python 里跑）：

```python
import re
print(re.findall(r"-?\d+\.?\d*", "上涨 72 个，跌 -0.43，成交 1.2 亿"))
# 结果：['72', '-0.43', '1.2']  ← 注意全是字符串，不是数字
```

### 第 2 句 `if x not in allowed:`

**人话**：如果 `x` **不在** `allowed` 这张名单里，就执行下面的代码。

**语法点**：

- **`in` = 成员测试**（在不在里面），`not in` = 取反。
- 它对面可以是列表、字符串、字典（查键）、集合都行。
- **它只回答 True / False**，不告诉你「排第几」。

**为什么必须这么写**：`allowed` 是「合法数字白名单」。文案里出现一个数字，先问「它在白名单里吗」——不在就是编的，立刻拦掉。这是整个 `check_numbers` 的核心动作。

**自己试**：

```python
print("张三" not in ["李四", "王五"])   # True
print("72" in {"72", "423"})          # True
```

---

### 第 3 句 `missing = allowed - set(found)`

**人话**：白名单里有、但文案里**没出现**的数字，全部挑出来存进 `missing`。

**语法点**：

- **`set(列表)` = 把列表转成集合**（不是「字符串化」）。
- **集合相减 `A - B` = 差集**：A 里有、B 里没有的。
- 为什么必须先转：`found` 是**列表**，列表没有定义「减」这个运算，会报 `TypeError`。

**为什么必须这么写**：这行是**漏写检查**——`nums` 里算出来 5 个数，摘要里只写了 3 个，另外 2 个就是 `missing`。一个数都没漏才说明模板没写残。

**自己试**：

```python
print({"a", "b", "c"} - {"b"})   # {'a', 'c'}
print(["a"] - ["b"])             # 报错：列表不支持减法
```

### 第 4 句 `text = f"今日 {nums['行数']} 个板块中，上涨 {nums['上涨']} 个，下跌 {nums['下跌']} 个。"`

**人话**：拼出一句通知文字，把 `nums` 里三个数**填进**句子对应位置，结果存进 `text`。

**语法点**：

1. **`f"..."` = f-string**（格式化字符串）。引号前那个 `f` 的意思是：**大括号里的东西当代码算，不当文字看**。
2. **`nums['行数']`** 是大括号里的内容——一个「按键取值」。外层的 `{}` 是 f-string 的占位符，内层的 `['行数']` 才是字典取值，**两层不是一回事**。

**必须纠正你上次的答案**：这行**不打印任何东西**。它只是**拼出一个字符串**。打印是 `print(text)` 干的。这两步一定要分开，否则你永远看不懂代码。

**能换的写法**（老写法，认识就行，别学）：

```python
text = "今日 {} 个板块中，上涨 {} 个".format(nums['行数'], nums['上涨'])
```

**自己试**：

```python
n = 90
print(f"共 {n} 行，翻倍是 {n * 2}")   # 大括号里能算，不只是插变量
```

### 第 5 句 `out = subprocess.run([sys.executable, "stats.py", str(csv_path)], cwd=ROOT, capture_output=True, text=True, encoding="utf-8", timeout=180)`

**人话**：**另外开一个程序**去跑 `stats.py`，把这个 CSV 的路径交给它，把它打印出来的内容抓回来，结果存进 `out`。

**语法点**：

- **`subprocess.run(...)` = 起一个子进程**（相当于在代码里替你敲了一次命令行）。
- 第一个参数是**列表**：第一个元素是「用哪个程序跑」，后面是「交给它的参数」。
- `sys.executable` = 当前这个 Python 解释器自己的路径（保证子进程用同一个 Python）。
- 后面几个全是**关键字参数**（写名字传的）：`cwd` 在哪个目录跑、`capture_output=True` 抓它的输出、`text=True` 让我拿到文字不要二进制、`encoding` 指定编码、`timeout=180` 最多等 3 分钟。

**为什么这行是整个项目的命门**：它是**另一个进程**，跟本文件里的 `build_nums` **不共享内存、不共享任何变量**。所以这两条路才是真独立的——这才叫「互校」。

别人问「你怎么保证不是同一份代码复制两遍」，答案就是这一行。

**自己试**：

```python
import subprocess, sys
r = subprocess.run([sys.executable, "-c", "print(1 + 1)"], capture_output=True, text=True)
print(r.stdout)          # 2
print(r.returncode)      # 0 表示成功
```

### 第 6 句 `head = "\n".join(out.stdout.splitlines()[:3])`

**人话**：把 `stats.py` 输出的**前 3 行**取出来，再用换行拼回一小段文字。

**从里往外拆四步**：

| 步 | 代码 | 结果类型 | 说明 |
|---|---|---|---|
| ① | `out.stdout` | 一个**大字符串** | 子进程打印的所有内容，一堆文字 |
| ② | `.splitlines()` | **列表** | 按行切开，每行一个元素 |
| ③ | `[:3]` | **列表**（更短） | **切片**，取前 3 个 |
| ④ | `"\n".join(...)` | 字符串 | 用换行把列表元素**粘**回一段文字 |

**语法点**：

- **切片 `[a:b]`**：从左往右数，取「第 a 个到第 b 个之前」。**只产生一段，不是把东西劈成两半**。
  - `lst[:2]` = 前 2 个
  - `lst[2:]` = 从第 3 个到末尾
  - `lst[1:3]` = 第 2、3 个（不含第 4 个）
- **`"分隔符".join(列表)`**：把列表拼成一个字符串，中间插分隔符。它是**字符串的方法**——所以分隔符写在点号左边。

**为什么必须这么写**：`stats.py` 后面还会打印「成交额 Top5 合计 0.00」这类干扰行，只取前 3 行（文件名 / n=… / r=…）才能干净地解析。

**自己试**：

```python
print([1,2,3,4][:2])        # [1, 2]
print("-".join(["a","b"]))  # a-b
```

### 第 7 句 `a = round(float(stats[k_stat]), 3)`

**人话**：从 `stats` 里按 `k_stat` 这个**变量**的值取出一个数，先变成数字，再保留 3 位小数，存进 `a`。

**从里往外**：

1. `stats[k_stat]` —— `k_stat` 是**变量**，它的值（比如 `"n"` 或 `"r"`）才是键。所以 `stats[k_stat]` = 「按变量里装的键名去取值」。
2. `float(...)` —— 因为 `stats` 里的值是从子进程文字解析来的，是**字符串** `"-0.2836"`，要转成数字才能算。
3. `round(..., 3)` —— 保留 3 位小数。

**为什么必须这么写**：`stats.py` 输出 4 位（`-0.2836`），`build_nums` 里是 3 位（`-0.284`）。不统一就天天误报。归一到 3 位再比，是**对齐口径**，不是放宽容差。

**自己试**：

```python
stats = {"n": "90", "r": "-0.2836"}
k = "r"
print(round(float(stats[k]), 3))   # -0.284
```

### 第 8 句 `if abs(a - b) > 1e-9:`

**人话**：如果 a 和 b 的差距**大于一个极小极小的数**，就认为它们真的不相等。

**语法点**：

- **`abs(x)` = 绝对值**（负数变正数）。所以 `abs(a - b)` = 两者差距，不管谁大谁小。
- **`1e-9` = 科学计数法**，就是 0.000000001（1 乘 10 的 -9 次方）。

**为什么不写 `if a != b:`**：因为**计算机存不下大多数小数**。`0.1` 在二进制里是无限循环，存进去就被截断成近似值，`0.1 + 0.2` 算出来是 `0.30000000000000004`，所以 `0.1 + 0.2 != 0.3` 在 Python 里是 **True**。`round` 之后也可能差 `1e-16`。直接比会天天误报。

**标准写法**（认识就行）：`if not math.isclose(a, b, abs_tol=1e-9):`

**自己试**：

```python
print(0.1 + 0.2)            # 0.30000000000000004
print(0.1 + 0.2 == 0.3)     # False  ← 这就是原因
print(abs(0.1 + 0.2 - 0.3) > 1e-9)   # False ← 用阈值就对了
```

## 3. 自测里你空着/答错的四条，再讲一遍

### ① 位置参数 vs 关键字参数

```python
def f(x, y):
    return x - y

f(1, 2)       # 位置参数：按顺序对号，1 给 x，2 给 y
f(x=1, y=2)   # 关键字参数：按名字对号，顺序随你
f(y=2, x=1)   # 同上，结果一样
f(1, y=2)     # 可以混用，但位置参数必须写在关键字参数前面
```

**项目里为什么用关键字**：`subprocess.run` 有十几个参数，全是开关（抓不抓输出、是不是文字、等多久）。靠名字传，顺序无关，也不会传错位。

### ② 五种数据怎么取一个元素

- str：`s[0]`（第一个字）
- list：`lst[0]`（第一个元素）
- dict：`d["键"]`（按名字取）
- **set：不能取**。只能 `x in s`（在不在）、`for x in s`（一个个过）
- DataFrame：`df["列名"]`（一整列）

你上次答的是「怎么转换」——转换（`str()`、`set()`）和取值是两件事，别混。

### ③ f-string 与 `.format`

```python
n = 90
print(f"n={n}")            # 推荐
print("n={}".format(n))    # 老写法
```

### ④ 切片

```python
lst = [1, 2, 3, 4]
lst[:2]     # [1, 2]        前两个
lst[2:]     # [3, 4]        从第三个到末尾
lst[1:3]    # [2, 3]        第 2、3 个
lst[-1]     # 4             最后一个
```

`[:2]` **只产生一段**，不是「劈成两半」。要两半必须写两次切片。
