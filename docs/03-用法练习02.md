<summary>热身 5 题答案（先自己写完再点开）</summary>

1. **布尔序列求和**——把 True 当 1 加起来 = 数个数。
2. **从大到小（降序）**。`ascending=False` 里的 False 就是「不升序」。
3. 等价于「**这一列全是空**」（一个非空都没有），写成 `df["x"].isna().all()` 更直白。
4. `"行数"` 是**字符串**，它是字典的**键**；`nums` 才是变量名。
5. 快在：集合**自动去重**，查一个元素是 O(1)（列表要一个个比）。丢掉的是：**哪个数字属于哪个字段**——所以「两个数对调位置」这种错拦不住。

</details>

<details>
<summary>第 8 句的答案（先自己想）</summary>

因为**浮点数不能用 `===` 判断相等**。`0.1 + 0.2 != 0.3` 在计算机里是真的。
`round(x, 3)` 之后也不保证精确：两个数学上相等的数，存成二进制后可能差 `1e-16`。
所以 `a != b` 会天天误报，正确写法是 `abs(a - b) > 1e-9`——**只看差值是否超过一个「可以忽略的极小量」**。

注意这和「不许放宽容差」不矛盾：`1e-9` 是**浮点表示误差**的量级（不是业务误差），业务口径的对齐是前面那句 `round(..., 3)` 在做的事。
</details>

## 逐句订正

### 第 1 句 `re.findall(r"-?\d+\.?\d*", text)`

**你错得最多的一句**，逐项纠正：

| 你写的 | 实际含义 |
|---|---|
| `d*` 是「指数」 | ❌ `\d` 是 **digit，数字 0-9**；`\d*` = 零个或多个数字 |
| 「反斜杠是分隔符」 | ❌ 反斜杠是**转义**：它让 `\d` 表示「数字类」，而不是字母 d |
| `r""` 的 r | 是 **raw string**：告诉 Python **不要转义反斜杠**。没有 r 就得写成 `"\\d+"`（双反斜杠） |
| `-?` | **可选的负号**（`?` = 前面那个字符可有可无） |
| `\.?` | **可选的小数点** |
| 「d+ 不知道什么意思」 | `\d+` = **一个或多个**数字 |

- **整句在干什么**：从 `text` 里找出所有形如 `-12`、`3.5` 的数字串，返回一个**列表**。
- **写法名字**：正则表达式匹配（`re.findall` = 找出全部匹配）。
- **能换吗**：能，更严格的写法是 `re.findall(r"-?\d+(?:\.\d+)?", text)`——它不会把「5.」这种半截也算进去。

### 第 2 句 `if x not in allowed:`

- 第 1 栏 ✅ 对。
- **写法名字**：`not in`——**成员测试取反**（判断「不在里面」）。「if 语句」说的是结构，不是这个写法。
- 能换吗：你写的 `if x in allowed: ... else:` 逻辑等价但多一层缩进，而且 **`else` 后面必须跟冒号**，你现在是空的。老实说这句**没有更好的换法**，`not in` 就是标准写法。

### 第 3 句 `missing = allowed - set(found)`

- **你第 1 栏有两处错**：`set(found)` 不是「字符串化」，是**把列表转成集合**；`-` 不是减法，是**集合差集**（A 里有、B 里没有的）。
- **整句**：算出「白名单里有、但文案里没出现的数字」——这就是「漏写检查」。
- **写法名字**：集合差集运算（`difference`）。
- **能换吗**：能，意思完全一样：`allowed.difference(set(found))`。

### 第 4 句 f-string 那句

- 第 1 栏基本对，但措辞要改：`nums` 是**字典**不是表；`nums['上涨']` 是「取字典里键 `上涨` 对应的值」。
- **你第 2 栏写「打印」——这是错的**：这行**不打印任何东西**，它只是**拼出一个字符串**存进 `text`。打印是 `print(text)` 那一行干的。
- **写法名字**：**f-string 格式化**（在字符串里用 `{}` 嵌变量/表达式）。
- **能换吗**：你写的 `text = {nums['行数']，nums['上涨']，nums['下跌']}` **语法是错的**（中文逗号，而且这是集合字面量，得到的是集合不是文字）。正确换法：
  ```python
  text = "今日 {} 个板块中，上涨 {} 个，下跌 {} 个。".format(nums['行数'], nums['上涨'], nums['下跌'])
  ```
  这是老写法，能用但啰嗦；f-string 是目前推荐写法。

### 第 5 句 `subprocess.run([...], cwd=..., capture_output=True, ...)`

（你说完全不知道——这句确实是新手最容易跳过的，讲清一次就够）

- **整句在干什么**：**另起一个程序**跑 `stats.py`，把 CSV 路径当参数传给它，把它打印出来的内容抓回来存进 `out`。
- **写法名字**：`subprocess.run()` **子进程调用** + **关键字参数**（`cwd`=在哪个目录跑、`capture_output`=抓输出、`text=True`=输出当文字不要二进制、`encoding="utf-8"`、`timeout=180`=最多等 180 秒）。
- **为什么这行是命门**：它是**另一个进程**，跟本文件里的 `build_nums` 不共享内存、不共享变量——**所以这两条路才是真独立**。面试讲「两条路互校」时，别人会问「你怎么保证不是同一份代码」，答案就是这一行。
- **能换吗**：能，`subprocess.check_output([...])` 只要输出不要退出码时更短；老写法 `os.popen` 不推荐。

### 第 6 句 `head = "\n".join(out.stdout.splitlines()[:3])`

- **整句在干什么**：把 `stats.py` 输出的**前 3 行**取出来，再用换行拼回一段字符串。
- 拆成四步（这就是「方法链」的读法，从里往外）：
  1. `out.stdout` = 子进程打印的全部内容（一个字符串）
  2. `.splitlines()` = 按行切成**列表**
  3. `[:3]` = **切片**，取列表前 3 个
  4. `"\n".join(...)` = 用换行把列表**拼回字符串**
- **写法名字**：字符串方法链 + **切片** + `join`（列表 → 字符串）。
- **能换吗**：能，`"\n".join(out.stdout.split("\n")[:3])`，等价；`splitlines()` 更稳，能处理 `\r\n`。

### 第 7 句 `a = round(float(stats[k_stat]), 3)`

- 第 1 栏方向对，两处措辞要改：`stats` 是**字典**不是表；`k_stat` 是**变量**，它的**值**才是键名（比如 `"n"`）。
- **写法名字**：**嵌套调用**（`float` 先把 `"−0.2836"` 这种字符串转成数字 → `round` 保留 3 位）+ **用变量当字典键取值**（`stats[k_stat]`）。
- **能换吗**：拆成两行更可读（不是必须）：
  ```python
  a_raw = float(stats[k_stat])
  a = round(a_raw, 3)
  ```

### 第 8 句 `if abs(a - b) > 1e-9:`

- **`abs()` 是什么**：取**绝对值**（负数变正数）。所以 `abs(a - b)` = 两个数的差距，不管谁大。
- **写法名字**：**浮点数用阈值比较**（不能写 `==`）。
- **为什么不能写 `if a != b:`**：浮点数在计算机里存的是近似值，`0.1 + 0.2 != 0.3` 是真的。`round(x, 3)` 之后也可能差 `1e-16`，直接比会天天误报。
- **能换吗**：能，标准库写法：
  ```python
  if not math.isclose(a, b, abs_tol=1e-9):
  ```
