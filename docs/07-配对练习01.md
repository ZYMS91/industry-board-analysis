漏的这两个恰好是这段代码的**全部意义所在**：一个是「另起进程」才有独立性，一个是「失败就退出」才有校验力度。

### 问 2：方向对，三处硬错

| 你说的 | 实际 |
|---|---|
| 「测试时间 100 秒」 | `timeout=180` → **180 秒**，读代码要一个一个对照，不能凭印象 |
| 「如果 out 经过 returncode 后不为空就返回 SystemExit 里的内容」 | **全反了**。是 `returncode != 0`（子进程**失败**）才 `raise SystemExit`；而且 `raise` 不是「返回」，是**抛异常、直接把整个程序终止掉** |
| 「换行转换成表等价给 head」 | `"
".join(...)` 是**把列表拼回一段文字**（字符串），不是表 |

第三处的根源：`join` 的方向是「列表 → 字符串」，反方向才是 `split`（字符串 → 列表）。你两个词一直混着用。

### 为什么第 2 处最要命

`returncode != 0` + `raise SystemExit` 这一对，就是整个校验程序的**态度**：

> 子进程算失败了，我宁可整个程序崩掉，也不能假装通过。

面试官问「你的校验脚本会不会误报通过」，答案就在这两行。讲反了就变成「出错了还返回内容」，逻辑正好相反。

### 面试版一句话（背这个，别背你刚才那段）

> 这个函数是校验的入口。它**另起一个进程**去跑 `stats.py`——注意是另一个进程，不共享任何变量，所以这才是真正独立的第二条路。拿回输出后只取前 3 行，用正则拆成键值对，`dict()` 变成字典返回。**如果子进程的退出码不是 0，就直接抛 `SystemExit` 终止**——校验程序自己失败时不能假装通过。

这段话把三个卖点全包了：独立进程、只取前 3 行（避免干扰数字）、失败就终止。

**2 / 6。** 但错的地方高度一致，全是你这两天反复踩的四个坑。

### 坑 1 · `int()` 是截断，不是四舍五入

```python
int(3.9)    # 3   不是 4
int(-3.9)   # -3  向零砍掉小数部分
```

要四舍五入得用 `round()`。**`int()` 只负责「变成整数」，不管小数。**

### 坑 2 · `split()` 返回的是列表，不是字符串

```python
"a,b".split(",")     # ['a', 'b']   列表，两个元素
"a b".split()        # ['a', 'b']   不传参数 = 按空格切
```

判断依据：**切分的结果一定是「多个东西」，多个东西就得用列表装。** 单看返回值类型就知道该不该再套 `for`。

### 坑 3 · `[-2:]` 是「从倒数第二个到末尾」

```python
[1,2,3,4][-2:]   # [3, 4]    两个元素
[1,2,3,4][-3:]   # [2, 3, 4] 三个
```

你把 `-2:` 当成了 `-3:`。**负号是「从右边数」，数字本身仍是「取几个」**：`-2` 起 → 剩两个。

### 坑 4 · 浮点比较**不会报错**，会安静地给你 False ← 这条最重要

```python
0.1 + 0.2          # 0.30000000000000004
0.1 + 0.2 == 0.3   # False   ← 不报错，不崩溃，就一个 False
```

你第二次答成「会报错」了。**真实情况更危险：它不报错。** 如果你写 `if a == b:` 去比两个小数，程序会一声不响地走进「不相等」的分支，跑完还告诉你一切正常。

这就是项目里要写 `if abs(a - b) > 1e-9:` 的原因——**不是防报错，是防静默误报**。

### `round()` 用的是「银行家舍入」，不是四舍五入

实跑对照（Python 3.14.5）：

| 输入 | 输出 |
|---|---|
| 2.5 | 2 |
| **3.5** | **4** |
| 4.5 | 4 |
| 5.5 | 6 |
| 2.51 | 3 |
| -2.5 | -2 |

规则：**正好在 .5 的时候，两个整数离得一样近，取「偶数」那一边。**

所以你昨天记住的「2.5 → 2」不是「往下取」，是「取偶数」；3.5 的偶数边是 4，4.5 的偶数边还是 4。

### 项目里为什么不受影响

`round(r, 3)` 里的 r 是相关系数（如 -0.28361…），落在恰好 `0.0005` 这种边界上的概率可以忽略。**但要知道这个规则存在**——面试问 `round(2.5)` 是多少，答 3 就露了。
