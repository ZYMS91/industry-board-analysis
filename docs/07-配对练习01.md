## 每行一句话（配对完之后再看，用来核对）

<details>
<summary>点开</summary>

1. `df['涨跌幅'] > 0` 出 True/False 序列，`.sum()` 当 1 加，`int()` 转整数 → **布尔序列求和**
2. 右边两个值一次算完，左边两个名字按顺序接 → **多重赋值**
3. 取列 → 取第一个 → `str()` 转字符串 → `[:10]` 取前 10 个字符 → 里面有**切片**
4. `.notna()` → `.sum()` → `== 0` 一路点下去 → **方法链**
5. 冒号后面的 `.{p}f` 决定打印长相，而且里层 `{p}` 先算出位数 → **格式说明符**
6. `__file__` → `.parent` → `/` 一级级接 → **Path 拼接**（`/` 不是除法）
7. `mkdir()` 里写 `exist_ok=True`，已存在就不报错 → **关键字参数**
8. `.items()` 拆成 (键, 值)，左边两个名字分别接 → **双变量解包**
9. 规则里的括号只返回括号内容，`findall` 给出 (键, 值) 列表，`dict()` 吃成字典 → **正则捕获组**
10. `.get(key, 0)` 没有键就返 0，再加 1 存回去 → **字典计数**

</details>
