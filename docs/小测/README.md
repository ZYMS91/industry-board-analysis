# 每日小测 · 规则

## 什么时候做
**每天学习结束时**，最后 3 分钟。不提前、不延后、不补做（除非当天没学）。

## 题量与判定
- **固定 5 题**，不再多也不减少
- **4 题以上 = 过**；3 题 = 半过，第二天开头补一题同类型；2 题以下 = 当天内容重讲
- 每题只写答案，不写解释（解释留给批改的时候问）

## 题型配比（固定，不随机）

| 题号 | 类型 | 考什么 |
|---|---|---|
| 1 | **名字题** | 给代码，说名字 |
| 2 | **名字题** | 给名字，说它干嘛 |
| 3 | **输出题** | 脑内执行，猜输出 |
| 4 | **原理题** | 为什么这样写 / 不这样写会怎样 |
| 5 | **坑题** | 从当天的错里挑一个，问错在哪 |

## 出题范围
**只考当天出现过的内容**，可以顺带 1 题复习前一天的。三天内没出现过的名字不考（避免考"上古知识"）。

小测的目的不是打分，是**当天暴露当天补**。拖到周末一起考，等于把 5 天的错攒成一次打击。
