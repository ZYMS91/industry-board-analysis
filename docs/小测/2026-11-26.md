<summary>答案（做完再看）</summary>

**1** `getattr` —— **取属性**。带默认值的意思是「取不到就给 None，不报错」。

**2** 验证的是「**坏东西一定会被拦住**」（这里必须抛异常），而不是「结果对不对」。

**3** `True`。`.lower()` 把 `UTF-8` 变成 `utf-8`，成员测试命中元组里第一个。

**4** 第一步：父进程按 UTF-8 解 GBK 字节 → **`UnicodeDecodeError`**，而且崩在读输出的**线程**里，所以 `out.stdout` 变成 `None`。
第二步：真正的异常发生在子进程读取阶段，父进程继续往下跑，到 `out.stdout.splitlines()` 才因为 None 报 `AttributeError`——**报错的位置被推迟了一行**。

**5** `text` 是**集合（set）**，不是字符串。因为 `{...}` 是集合的写法。赋值时不检查类型，`check_numbers` 一路传到 `re.findall(pattern, string)` 才检查，于是报
`TypeError: expected string or bytes-like object, got 'set'`。**动态语言的类型错误是延迟暴露的。**
