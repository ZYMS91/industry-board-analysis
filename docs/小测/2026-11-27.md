## 5（坑题）为什么这样写会直接报错？

```python
with pytest.raises(SystemExit()):

```

答：______

<details>
<summary>答案（做完再看）</summary>

**1** ① **上下文管理器**（`with` 协议：进入调 `__enter__`、退出调 `__exit__`）；② `e` 是 **`ExceptionInfo` 对象**（包装盒，异常本体在 `e.value`）。

**2** 被包住的代码**没有抛** `SystemExit` —— 断言"必须报错"落空了，所以测试挂。**不是**"负向测试通过"，恰恰是负向测试失败。

**3** `['23', '0.5'] list` —— 抠出来的是**字符串**列表，`0.5` 也在里面（它不在白名单 → 校验会拦）。

**4** 因为 **`SystemExit` 不是 `Exception` 的子类**（它继承 `BaseException`）。这样 `generate()` 里的 `except Exception` 不会把「校验失败」误当成「LLM 不可用」而静默降级成模板。

**5** `SystemExit()` 带括号 = **异常实例**，而 `pytest.raises` 要的是**异常类**。实测报
`TypeError: Expected a BaseException type, but got an exception instance: SystemExit`。

</details>
