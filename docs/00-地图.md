## 二、两处已实测到的洞（作业从这里来，别问我答案）

**洞 A：`/summary` 这条路上没有 `check_numbers`。**
`generate()` 里只有 `llm_summary` / `template_summary`；`check_numbers` 写在 `if __name__ == "__main__":` 里。
→ 你要回答：**这算不算缺陷？** 算的话最小改法是什么？不算的话为什么？

**洞 B：跑一次 `python summarize.py`，输出里两句话互相打架。**（2026-11-19 11:00 实测原文）

```
今日 496 个板块中，上涨 75 个，下跌 420 个。（本数据源不含成交额字段，相关性与集中度指标不可用。）
今日A股行业板块普遍下跌，资金明显向头部集中而非分散。
校验通过：3 个数字全部可溯源
```

前一句说「集中度不可用」，后一句说「资金向头部集中」，而校验照样打印「通过」。
→ 你要回答：**校验为什么没拦住？**（提示方向：它比的是什么？评述里有没有数字？）
