## 逐句订正

### 第 1 句 `df = load_csv(CSV_latest)`

- **你的答案**：基本对（「抓取出来转换成一张表」）。
- **写法名字**：函数调用 + 位置参数 + 返回值赋值。
- **补一句**：`CSV_latest` 是一个**文件路径常量**（模块第 9 行定义），不是数据。
- **能换吗**：能。`df = load_csv(path=CSV_latest)`（如果参数名是 path）。
- ⚠️ **昨天发现的坑**：`summarize.py:11` 的**参数名也叫 `CSV_latest`**，把第 9 行的常量遮蔽了——函数体里的 `CSV_latest` 是传进来的值，不是那个常量。这就是为什么少传一个参数会报 `TypeError: build_nums() missing 1 required positional argument`。

### 第 2 句 `if df["涨跌幅"].notna().sum() == 0: raise ...`

- **你第 1 栏写错了一处**：不是「先判断是否为空**或者** sum 为空」，这里是**串联**：
  `.notna()` 逐个判断「不是空值」→ 得到一串 True/False；`.sum()` 把 True 当 1 加起来 → **非空值的个数**；`== 0` → 一个非空都没有 → **整列全空**。
- **写法名字**：Series 方法链 + 布尔序列求和 + 主动抛异常（`raise ValueError`）。
- **能换吗**：能，而且更好读：
  ```python
  if df["涨跌幅"].isna().all():
      raise ValueError("涨跌幅列全为空，本份快照无法使用")
  ```
- **你写的替换版有 3 处错**：`ruturn` 拼错了；`else` 后面缺冒号；函数里不存在「返回 0 表示出错」这种约定（`raise` 已经把程序停住了，后面写 `return 0` 是废话）。

### 第 3 句 `n = len(df)` / `up = int((df["涨跌幅"] > 0).sum())`

- **你的答案**：方向全对。「括号先算」也说对了——这是运算优先级：比较运算先出布尔序列，`.sum()` 再数。
- **写法名字**：布尔序列求和（True 计 1）+ 类型转换。
- **`int()` 为什么必须加**：`.sum()` 返回的是 **numpy 的整数类型**（`numpy.int64`），不走 `int()` 后面写 JSON 会报 `not JSON serializable`。这不是多余。
- **能换吗**：能。`up = int(len(df[df["涨跌幅"] > 0]))`——先筛行再数行数，意思一样。

### 第 4 句 `nums = {"行数": n, "上涨": up, "下跌": down}`

- **你的第 2 栏写错了**：「创建一个字典赋值给一个字符串」——`nums` 是**变量名**，不是字符串；`"行数"` 才是字符串，它是**键**。
- **措辞纠正**：字典里不叫「一列」，叫**一对键值对**（key-value）。「列」是 DataFrame 的说法。
- **写法名字**：字典字面量（dict literal）。
- **能换吗**：能。`nums = dict(行数=n, 上涨=up, 下跌=down)`——中文也能当参数名。

### 第 5 句 `if "成交额" in df.columns and df["成交额"].notna().any():`

- **`df.columns` 是什么**：列名清单（Index 对象），`"成交额" in df.columns` 就是在问「这张表有没有这一列」→ 返回 True/False。
- **`.notna().any()`**：任一非空就为真 = **这一列至少有一个真数据**（不是整列空）。
- **写法名字**：成员测试 `in` + 逻辑与 `and` + **短路求值**（左边 False 时右边根本不算——所以列不存在也不会 KeyError，这是 `and` 真正的价值）。
- **能换吗**：能。`if "成交额" in df and ...`（DataFrame 的 `in` 也是查列名）；`notna().any()` 可换成 `not df["成交额"].isna().all()`。

### 第 6 句 `r = round(df["涨跌幅"].corr(df["成交额"]), 3)`

- **你的答案**：对。两个都认得出来。
- **写法名字**：`Series.corr()` = **皮尔逊相关系数**（−1 到 1）；`round(x, 3)` 保留 3 位。
- **补一句**：pandas 的 `corr` 默认**成对跳过空值**；如果成交额整列是空，结果是 `NaN`——这就是东财那份数据算不出 `r` 的原因。

### 第 7 句 `top5 = df.sort_values("成交额", ascending=False).head(5)` …

- **你第 1 栏有一处错**：`ascending=False` 是**从大到小（降序）**，你写「非从小到大的排序」——方向是对的，但说法绕，面试会以为你不确定。
- **第二处错**：「求和的**个数**」——`sum()` 求的是**金额之和**，不是个数。`conc` 是「前五名成交额之和 ÷ 全部成交额之和 × 100」= **前五集中度百分比**。
- **写法名字**：链式调用（`.sort_values().head()`）+ Series 求和。
- **能换吗**：能，而且更干净：`top5 = df.nlargest(5, "成交额")`——一步取出最大的 5 行。

### 第 8 句 `for v in nums.values(): allowed.add(str(v))`

- **你答串题了**：你写的是上一段代码（`text` / 正则 / `found`）的内容。这句跟正则**没有关系**。
- **它在干什么**：把 `nums` 字典里每个值取出来（`n`、`up`、`down` 那些数），转成字符串，塞进 `allowed` 这个**集合**。
- **写法名字**：`for` 遍历 + `dict.values()` + 集合 `add()` + `str()` 转换。
- **能换吗**：能，一行：`allowed = {str(v) for v in nums.values()}`（集合推导式）。
- ⚠️ **为什么这里必须是集合而不是列表**：集合**去重 + O(1) 查找**，所以校验很快。但代价是——**它只记得「有哪些数字」，不记得「哪个数字属于哪个字段」**。这就是昨天实验里「两个数对调位置，校验拦不住」的根因。这个坑必须自己讲得出来，面试会问。

## 8 个必须记住的写法（今天记，明天用第二组验）

| #   | 写法      | 长相                                        | 一句话记住                        |
| --- | ------- | ----------------------------------------- | ---------------------------- |
| 1   | 函数调用取值  | `x = f(a)`                                | 括号里是参数，等号左边接返回值              |
| 2   | 方法链     | `a.b().c()`                               | 每一步返回新对象，能一直接下去              |
| 3   | 布尔序列求和  | `(col > 0).sum()`                         | True 当 1 加起来 = 数个数           |
| 4   | 任一 / 全部 | `.any()` / `.all()`                       | 有一个是 True / 全是 True          |
| 5   | 字典字面量   | `{"键": 值}`                                | 键是字符串，值是变量                   |
| 6   | 成员测试    | `x in 容器`                                 | 列名、列表、字符串都能问                 |
| 7   | 降序取前 N  | `sort_values(k, ascending=False).head(n)` | `False` = 从大到小；可换 `nlargest` |
| 8   | 集合      | `set()` / `.add()` / `{... for ...}`      | 去重、快，但**丢掉顺序和标签**            |
