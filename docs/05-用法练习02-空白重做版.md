### 三处真错（必须改，尤其第 1 条）

#### 错 1 · 第 4 句第 3 栏：f-string 和 `.format` 不能混用

你写的：

```python
text = f"今日{}剩下的同理".format({nums['行数']}剩下的同理)
```

**三处错叠在一起**：

1. 加了 `f` 前缀，`{}` 就会被当**代码**算。空 `{}` 直接报 `SyntaxError`。
2. `.format()` 括号里**不能再套大括号**，直接写值。
3. 全角括号/引号，粘进 Python 里第一行就报错。

正确写法（两者只能选一个）：

```python
# 写法一：f-string（推荐）
text = f"今日 {nums['行数']} 个板块中，上涨 {nums['上涨']} 个，下跌 {nums['下跌']} 个。"

# 写法二：.format（不要加 f 前缀）
text = "今日 {} 个板块中，上涨 {} 个，下跌 {} 个。".format(
    nums['行数'], nums['上涨'], nums['下跌']
)
```

**口诀**：`f"..."` 里不写 `.format`；`.format` 里不写 `f`，`{}` 里也不放变量名。

#### 错 2 · 自测 3：DataFrame 是能取的

你写「不能 df[钱]」。**DataFrame 恰恰就是用 `df["列名"]` 取的**——项目里 `df["涨跌幅"] > 0` 天天在跑。

不能取的是 **set**。你把这两个搞反了。

| 类型 | 写法 |
|---|---|
| set | **不能取**，只能 `x in s` |
| DataFrame | `df["列名"]` 取一整列；`df.loc[0, "列名"]` 取一个格子 |

#### 错 3 · 自测 1：`a = b = []` 不是「不确定」

你写「变{}的值是不确定的」。它**很确定**：

```python
a = b = []      # a 和 b 是同一个列表的两个名字
a.append(1)     # 往这个列表里塞 1
print(b)        # [1]  ← b 跟着变了，因为就是同一个东西
```

不是「不确定」，是**两个名字指着同一个对象**。数字 1 是不可变的，所以 `a = 2` 只是把 a 换个地方贴；列表是可变的，改它就等于改两个名字看到的东西。

### 一个通病：全角符号（这个会浪费你很多小时）

你这次至少 6 处用了全角字符，粘进 Python 全部报 `SyntaxError`，而且报错信息不会告诉你是全角：

| 你打的 | 该打的 | 出现在 |
|---|---|---|
| `（）` | `()` | 第 3 句、第 4 句、第 6 句 |
| `｛｝` | `{}` | 第 4 句、自测 6 |
| `“ ”` | `" "` | 第 4 句、自测 6 |
| `，` | `,` | 第 5 题 `{1，3}` |

**规矩**：代码里除了字符串内部的文字，**所有符号都是英文半角**。中文输入法状态下写代码，打完括号就按一次 Shift。

### 第 3 栏你空着的 5 处，补上

**第 1 句**（正则）：能换的写法是把反斜杠写成两遍，不加 `r`：

```python
found = re.findall("-?\\d+\\.?\\d*", text)   # 不加 r 就得写双反斜杠（每个 \ 都要打两遍）

```
**不能换**的是「正则」本身——不用正则就得手写一堆 `for` + 判断，慢十倍。

**第 5 句**（子进程）：能换的是另外两个函数，但**不能换成普通函数调用**：

```python
out = subprocess.check_output([sys.executable, "stats.py", str(csv_path)], text=True)
```
`check_output` 只要 stdout 不要 returncode，省一步。但本质仍是**另起进程**——这一点不能换，否则两条路就变成一条了。

**第 6 句**（取前 3 行）：能换成两行写，更好读：

```python
lines = out.stdout.splitlines()
head = "
".join(lines[:3])
```
或者 `out.stdout.split("
")[:3]`——差别是 `splitlines()` 能处理 Windows 的 `

`，更稳。

**第 7 句**（保留 3 位）：能换，但要在**比的时候**统一，别在取的时候各留各的：

```python
a = float(stats[k_stat])
b = float(nums[k_num])
if abs(a - b) > 0.0005:      # 允许 3 位小数最后一位差 1
```
项目里选的是「取的时候就四舍五入到 3 位」，两边口径一致，比的时候直接比。

**第 2 句**（成员测试取反）：能换，但别用 `if/else` 套一层：

```python
if not (x in allowed):        # 写法一
    raise SystemExit(...)
```
写成 `if x in allowed: pass else: raise` 也行，但 `not in` 本来就是为这个场景造的，别绕。
