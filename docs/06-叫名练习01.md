<summary>点开看答案（先自己填完再点）</summary>

| # | 名字 |
|---|---|
| 1 | **布尔序列求和 + 类型转换**：`df['涨跌幅'] > 0` 得到一个 True/False 序列，`.sum()` 把 True 当 1 加起来，`int()` 转成整数 |
| 2 | **多重赋值（一次给两个名字）**：右边两个值一次算完，左边按顺序对号 |
| 3 | **方法调用，把一整列当参数传进去**：`.corr()` 算两列的相关系数 |
| 4 | **四步串起来**：取列 → 取第一个 → 转字符串 → 切片取前 10 个字符（拿日期） |
| 5 | **方法链 + 比较**：`.notna()` 判断非空、`.sum()` 数个数、`== 0` 判「一个都没有」 |
| 6 | **f-string 的格式说明符**，而且是**嵌套**的：`{p}` 先算出小数位数，`.{p}f` 再拿它当格式 |
| 7 | **路径拼接**：`Path` 的 `/` 运算符（不是除法），自动处理分隔符 |
| 8 | **关键字参数**：`exist_ok=True` 意思是「已存在就别报错」 |
| 9 | **字典遍历 + 双变量解包**：`.items()` 一次给出键和值，左边两个名字接住 |
| 10 | **正则捕获组 + `dict()` 直接吃**：`(\w+)` 抓键、`(-?[\d.]+|NA)` 抓值，`findall` 返回「键值对」的列表，`dict()` 把它变成字典 |
